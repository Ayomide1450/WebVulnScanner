## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Browser → `/assets/new` | Untrusted user-supplied name/target/cadence/scan-type/authorization-checkbox input crosses here |
| Scheduler thread → DB | No user request in the loop — the tick handler must independently re-derive trust decisions (tier, SSRF-safety) it cannot inherit from a request context |
| Session cookie → org-scoped resource | Any authenticated user of one org/solo-account must not read or mutate another org's/solo-account's Assets |
