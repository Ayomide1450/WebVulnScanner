<objective>
Close SEC-01: prove, executably, that every route in the app which accepts an object ID refuses a
caller from another org - and make that guarantee survive the next route somebody adds.

08-RESEARCH.md read every ID-accepting route this session and found the ownership guards already
correct almost everywhere. So this plan is a test-coverage closure, not a code fix: it lands the
three genuinely-uncovered cases (org invitation resend/revoke, scan CSV export, asset schedule) and
then replaces "we checked the list once" with a url_map enumeration lock that fails loudly the day
someone registers an ID-accepting route with no denial test behind it.

Purpose: SEC-01 is the highest-blast-radius requirement in the phase (D-04) - a hit here is a full
authorization bypass across the whole multi-tenant model.
Output: `tests/test_cross_org_idor.py` (new), extended `tests/test_org_routes.py` and
`tests/test_scan_ownership.py`, and a recorded route-inventory table in the plan summary.
</objective>
