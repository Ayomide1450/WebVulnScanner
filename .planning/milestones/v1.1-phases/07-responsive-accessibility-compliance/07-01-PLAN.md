<assumption_delta_decision>
**Signal:** this phase introduces a singular -> plural shape change: one `<table>` rendering of a
record collection becomes a `<table>` + a `.mobile-record-cards` list rendering of the same
collection.

**Decision: `no-change`.** The `<table>` stays the canonical, primary presentation of the data.
The card list is a presentational alternate view of the *same* Jinja collection, iterated by the
same for-loop over the same objects, inside the same `{% if %}` conditional - it is not a second
data model, a second query, or a second source of truth. No route, model, or query changes. The
only invariant this creates is markup-level and is captured as a must_have: both blocks must
iterate the same collection so row order and record count cannot diverge.

Advisory only - this checkpoint records the decision, it does not block the phase.
</assumption_delta_decision>
