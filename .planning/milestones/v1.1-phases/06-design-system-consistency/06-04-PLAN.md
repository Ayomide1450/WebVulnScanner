<general_snapping_rule>
Identical to the rule 06-03-PLAN.md states, applied here to `scan_report.html`'s and `scan_compare.html`'s
large `.sp-*`/other local blocks not called out as a specific, named fix below:
- `10.5px`-`12.5px` on an uppercase/letter-spaced/label-like element → **11px** (Caption role); a
  plain-case secondary/meta line → **13px** (Small role).
- `13.5px` anywhere → **13px** (Small role, or Label role if it is a form `<label>`).
- `14.5px`/`16px`/`16.5px` on body-adjacent paragraph text → **15px** (Body role).
- `font-weight: 700`, `800`, or `500` anywhere → **600** (or **400** for a full-sentence instructional
  label previously at 500 — see the named checkbox-label fixes below), with zero exceptions.
- Monospace **code-excerpt** text (a `<pre>` block, or a `.sp-evidence`-style raw HTTP-evidence line) is
  a deliberate, documented density exception, like `marketing.html`'s `.terminal pre` — leave its
  current literal `font-size` unchanged unless named otherwise below.
- `border-radius: 10px` on a form control → `var(--radius-sm)`; on a non-control container (an
  accordion/details wrapper, a card-like block) → `var(--radius)` (12px, the existing finding/alert-box
  radius family — this is the only place in the phase where 10px snaps to `--radius` rather than
  `--radius-sm`, because the consumer is a container, not a control; see `.adv-group` below).
</general_snapping_rule>
