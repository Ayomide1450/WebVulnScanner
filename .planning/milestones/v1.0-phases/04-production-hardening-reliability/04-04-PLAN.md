## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scheduler -> scan dispatch | An unattended, nobody-watching code path decides tier, SSRF safety and scan parameters on behalf of a user who is not present. |
| background thread -> DB | `_run_scan_in_background` is the only writer of `Scan.status`/`risk_score` and of `Report` rows for scheduled and manual scans alike. |
| test suite -> network and filesystem | These tests drive the exact code path that, unstubbed, performs real scans and writes real report files. |
