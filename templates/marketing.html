    Coverage
    
What WebVulnScanner checks

    
Every scan pulls from the same rule-based check engine - no black box, no guessing what was actually tested.

  

  

    

      

        
        
Exposed secrets
API keys and tokens leaked in page source or JS bundles.

      

      

        
        
Sensitive files
Backups, config files, and directory listings left reachable.

      

      

        
        
Security headers
CSP, HSTS, X-Frame-Options and the rest of the response header set.

      

      

        
        
TLS configuration
Certificate validity, expiry, and chain of trust.

      

      

        
        
CORS misconfiguration
Overly permissive cross-origin sharing rules.

      

      

        
        
Open redirects
Links that can be abused to redirect users off your domain.

      

      

        
        
Vulnerable JavaScript
Outdated front-end libraries with known CVEs.

      

      

        
        
Attack-surface discovery
Same-origin crawl to map reachable pages and endpoints.

      

      

        
        
DNS & email security
SPF, DMARC, and CAA records that stop domain spoofing.

      

      

        
        
Directory exposure
Open port scanning and directory listing detection.

      

      

        
        
Subresource integrity
Third-party scripts loaded without an SRI hash.

      

      

        
        
HTTP method exposure
Dangerous verbs (PUT/DELETE/TRACE) left enabled.

    Process
    
How it works

  

  

    

      

        
01

        
Enter your domain

        
Give WebVulnScanner a URL and confirm you own or are authorized to test it.

      

      

        
02

        
We verify ownership

        
Intrusive checks require a DNS TXT record or a /.well-known/ file tied to your org - not just a checkbox.

      

      

        
03

        
Checks run live

        
Watch each check start, complete, and surface findings in real time as the scan progresses.

      

      

        
04

        
Get a scored report

        
A graded, prioritized report with plain-English remediation steps for every finding.
