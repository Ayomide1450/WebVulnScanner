Advanced / authenticated checks ▸

Runs separately from the scan above, with deeper multi-technique probing (auth-bypass + time-based blind SQLi, UNION + error-based + time-based blind SQLi, three XSS payload variants, cross-account + anonymous IDOR, and a rate-limit check on brute-force). Fill in only the groups you have data for - each runs independently. Session cookies should come from disposable test accounts you created yourself.

SQLi auth-bypass + brute-force (login form)

Both checks share the login form's fields below.

SQLi UNION / error-based / time-based probe

Tries UNION-based confirmation first, then error-based, then time-based blind - never dumps real data.

Stored XSS (test account)

Tries three payload tag variants (svg/img/script) so a filter blocking one doesn't hide the finding.

IDOR (cross-account + anonymous access)

Needs two disposable test accounts you control. Also checks whether the resource is readable with no auth at all.
Media discovery (optional) ▸

Runs separately from the scan above. Crawls the homepage plus a few linked pages (prioritizing gallery/portfolio/media/video-sounding links) for images and videos - including lazy-loaded (data-src), responsive (srcset), CSS background-image, and embedded YouTube/Vimeo/Wistia players. Flags files in suspiciously-named paths (e.g. /private/, /backup/) that are publicly reachable, and checks JPEGs for leaked EXIF metadata (GPS location, camera/author info). Can optionally save copies of found files to disk.

Reports are saved to reports/ next to this app. A full scan takes roughly 20–45s; advanced and media checks can take longer.
